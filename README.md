# CopyToBaleBot

ربات همگام‌سازی کانال **تلگرام ⇄ بله**، کاملاً سرورلس روی [Telegram Serverless](https://core.telegram.org/bots/serverless).
هر کسی می‌تواند کانال تلگرام و کانال بله‌اش را به هم وصل کند تا پست‌ها (دوطرفه یا یک‌طرفه) خودکار منتقل شوند.

A serverless Telegram ⇄ Bale channel-sync bot running entirely on Telegram Serverless (`@tgcloud`).

## امکانات

- اتصال هر کانال تلگرام به یک کانال بله با کد یک‌بارمصرف (اثبات ادمین بودن در هر دو طرف)
- همگام‌سازی متن، عکس، ویدیو، گیف، فایل، موزیک، ویس، آلبوم، استیکر، لوکیشن، مخاطب و نظرسنجی (به‌صورت متن)
- همگام‌سازی ویرایش‌ها، ریپلای‌ها و سنجاق؛ حذف دوطرفه با `/del` (ریپلای روی پست) یا فوروارد به ربات
- تبدیل قالب‌بندی (بولد، ایتالیک، لینک) بین entityهای تلگرام و مارک‌داون بله
- تنظیمات هر اتصال: جهت (دوطرفه/یک‌طرفه)، توقف، جایگزینی خودکار یوزرنیم و لینک کانال، قوانین جایگزینی متن،
  سربرگ و امضا برای هر جهت، فیلتر کلمات، `#nosync`، فیلتر نوع محتوا، حذف لینک/منشن، ارسال بی‌صدا و...
- ارسال پست‌های قدیمی با فوروارد کردن آن‌ها به ربات
- عضویت اجباری جداگانه برای کاربران تلگرام و بله
- پنل مدیریت: آمار کامل، پیام همگانی، مدیریت/مسدودسازی کاربر، همهٔ اتصال‌ها، وضعیت سیستم و خطاها

## معماری

Telegram Serverless فقط با آپدیت‌های تلگرام اجرا می‌شود و تایمر ندارد (هر اجرا حداکثر ~۳۰ ثانیه).

- **Self-wake tick** (`lib/tick.js`): ربات یک نظرسنجی می‌فرستد و فوراً می‌بندد؛ بستن نظرسنجی توسط خود ربات
  یک آپدیت `poll` تولید می‌کند که `handlers/poll.js` را در یک اجرای تازه بیدار می‌کند.
- **Bale pump** (`lib/pump.js`): با قفل اتمیک، حدود ۲۰ ثانیه `getUpdates` بله را long-poll می‌کند، پست‌های کانال را
  در صف می‌گذارد، پیوی بله را پاسخ می‌دهد و دوباره خودش را tick می‌کند. `watchdog` روی هر آپدیت تلگرام، زنجیره را
  در صورت قطع شدن دوباره راه می‌اندازد.
- **Job queue** (`lib/queue.js`): انتقال فایل‌ها و ارسال‌ها در ورکرهای جداگانه (حداکثر ۳ هم‌زمان) انجام می‌شود؛
  کارهای هر اتصال به‌ترتیب اجرا می‌شوند تا ترتیب پست‌ها حفظ شود. تلاش مجدد با backoff و اطلاع به صاحب اتصال.

```
handlers/   update handlers (message, channel_post, edited_channel_post, callback_query, poll, my_chat_member)
lib/        bale client, platform adapter, text/format engine, sync, queue, pump, UI screens, admin
schema.js   SQLite schema
scripts/    gen-secrets (from .env), tgcloud wrapper, command menu setup
```

## راه‌اندازی

```bash
cp .env.example .env        # توکن‌ها را پر کن
npm install
npm run deploy              # lib/secrets.js را از .env می‌سازد و push می‌کند
npm run migrate -- --yes    # اعمال اسکیمای دیتابیس
npm run commands            # ثبت منوی دستورات در هر دو ربات
```

سپس یک‌بار پمپ را روشن کن: در ربات تلگرام `/admin ← 🫀 وضعیت سیستم ← 🔄 راه‌اندازی مجدد پمپ`
(یا هر پیامی به ربات بفرست؛ watchdog خودش پمپ را روشن می‌کند).

**چت تیکر:** به‌طور پیش‌فرض tickها در پیوی ادمین فرستاده و فوراً پاک می‌شوند. یک کانال خصوصی خالی بساز، ربات را
ادمین کن و از `پنل مدیریت ← وضعیت سیستم ← ⏱ تیکر` ثبتش کن.

## محدودیت‌ها

- API تلگرام و بله حذف پست کانال را اطلاع نمی‌دهند؛ حذف دوطرفه با `/del` یا فوروارد به ربات انجام می‌شود.
- فایل‌های بزرگ‌تر از ۲۰ مگابایت (سقف `getFile`) منتقل نمی‌شوند.
- ویرایش مدیا (تعویض فایل) منتقل نمی‌شود؛ ویرایش متن و کپشن منتقل می‌شود.

## Secrets

Tokens live only in `.env` (git-ignored). `scripts/gen-secrets.mjs` writes the Bale token into
`lib/secrets.js` (git-ignored) which is deployed with the rest of `lib/`.
